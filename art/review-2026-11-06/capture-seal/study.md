# CAPTURE-SEAL studies

All modes use Move V2, ring, linear lanes, Burst V2 and wake protection. Baseline and single-switch comparisons also use guard/flat; full uses the exact requested combination without guard/flat. Thus full is a package test, not a clean estimate of one rule.

CPU Normal uses its existing 12f reaction setting; opponent policies observe visible state through 15f. Skilled/mash bouts use 10/15f for both seats, five seeds and mirrored seats. CPU API drives only P2; all ordered pairs, no claim of mirrored CPU seats.

Ranges conservatively envelope Wilson and 2,000 ordered fighter-role pair block resamples, keeping seeds/seats within blocks. Overlapping baseline ranges mean could be luck, not proof of equivalence. Exploratory, without multiple-comparison correction.
